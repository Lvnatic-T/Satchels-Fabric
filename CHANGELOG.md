# Changelog v1.0.0:

### Initial Fabric Release
- Ported Vercte's Satchels from NeoForge to Fabric
- Replaced NeoForge-specific functionality with Fabric API implementations
- Replaced Curios integration with Accessories, including a dedicated Satchel equipment slot
- Preserved & ported most of the original mod features to stay as faithful to it as possible

### Changes from the original mod:
- Expanded config by adding an option to blacklist certain items from being put into the satchel
- Increased size of the Satchel belt by a little bit to remove some Z fighting with mods like 3D Skin Layers installed
- Added optional compatibility for Sophisticated Backpacks, including putting the backpacks into the satchel & using it from there with right click or the "open backpack" hotkey _(if for whatever reason people prefer the "immersiveness" of putting a big bag into a small bag kekw)_


That's just the initial release! More compatibility improvements may follow as additional mods and multiplayer environments are tested by you guys.
