# Changelog v1.0.0:

### Initial Fabric Release
- Ported Vercte's Satchels from NeoForge to Fabric
- Replaced NeoForge-specific functionality with Fabric API implementations
- Replaced Curios integration with Accessories, including a dedicated Satchel equipment slot
- Preserved & ported most of the original mod features to stay as faithful to it as possible

That's just the initial release! More compatibility improvements may follow as additional mods and multiplayer environments are tested.
